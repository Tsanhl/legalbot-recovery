## Implemented repairs

1. **Provider-specific context budgets.** Hosted/Codex calls no longer inherit the small Qwen context/output limits. They receive all applicable guidance rules; verifier input size is enforced rather than silently truncated. Qwen retains its separate profile.
2. **Safe, meaningful section headings.** The host preserves known GE/Essay/PB roles instead of replacing every heading with “Analysis N”, which had undermined its own structure scorer. Unknown headings still cannot publish unchecked legal prose.
3. **Facts versus law.** An application claim must quote exact user facts, depend on supported rule claims and cite their evidence. The reviewer receives these assumed facts separately. The selected answer contract preserves factual and legal dependencies instead of calling every claim a legal rule. Invented facts and broken dependencies still hold.
4. **Actionable quality repairs.** A writing-standard failure still blocks release but now identifies the rule and affected section. It no longer incorrectly counts as an immutable evidence-safety failure that skips semantic review and repair.
5. **Length validation.** More than 15% over the substantive word target blocks full release and requests a scoped condensation. The host does not cut legal prose mechanically. The bounded diagnostic revision used a stricter ±10% check; neither is a guarantee that generation will meet its target.
6. **OSCOLA and requested end list.** The host renders inline OSCOLA by default and appends a requested bibliography grouped into Case law, Legislation and Secondary sources, omitting empty groups and duplicates. Pinpoints remain in the body. Bibliography words are excluded from the body count. This is the requested chat grouping; OSCOLA conventionally treats the primary groups as tables.
7. **Privacy-scanner crash.** UUID digits were mistaken for phone numbers when the complete gap JSON was scanned. Opaque identifiers now receive structural checks and prose receives privacy checks; real phone numbers remain redacted. Both actual failing messages completed after repair.
8. **Missing-document detection.** A statement that there was no attachment no longer triggers an attachment request.
9. **Legislation version dates and extent.** An explicit dated representation can use an earlier version-start date only with an applicable interval and a separate current effects capture. England and Wales are checked individually. The actual CRA probe then held for outstanding effects, rather than accepting them silently. This component change does not enable online research in the development chat lane or admit sources.
10. **Review provenance.** Model identity follows the selected provider rather than labelling a Codex review as Qwen. Checkpoint identities also bind the selected provider’s generation budget, preventing reuse across changed profiles. The full-answer prompt distinguishes GE, Essay and PB and assesses the rendered citation output.

The XML date/extent repair follows the [official legislation XML documentation](https://legislation.github.io/data-documentation/formats/xml.html). Citation formatting follows the [Oxford OSCOLA guidance](https://www.law.ox.ac.uk/oscola). These references support implementation rules, not approval of the diagnostic legal answers.
