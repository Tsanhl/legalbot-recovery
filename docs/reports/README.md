# Dated reports are historical

Files in this directory record the state observed at their stated date/commit.
They are not live architecture or promotion instructions. Where a report
conflicts with `docs/CURRENT_STATE.md`, the current-state document and current
machine-readable policies control. Reports that described retrieval v1.0,
point-in-time currentness, two-process production, or an already-promotable
diagnostic build are superseded.
